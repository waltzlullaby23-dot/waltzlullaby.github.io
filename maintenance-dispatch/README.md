# 台電維護勤務與派車管理系統

此資料夾包含可由 GitHub Pages 提供靜態託管的前端版勤務派車工具。

## 功能

- 建立每日維護勤務：出勤日期、電廠／變電所、維護單位、集合時間、截止時間與備註
- 登錄人員：姓名、部門必填；性別、供餐狀態、電話選填
- 維護常用人員名冊，將人員快速加入不同勤務
- 依可調整的人數門檻建議大巴／小巴與所需車數
- 登錄車輛、核定乘客數、車牌與備註，檢查載客容量
- 截止時間鎖定名單、保存截止快照，支援依原因重新開放
- 查看勤務總覽、歷史紀錄與異動紀錄
- 匯出 CSV 報表、列印勤務表、JSON 備份及還原
- 響應式版面，支援桌面及手機瀏覽器

可能的網址路徑需依 Repository 的 Pages 設定確認：

## 重要限制與個資提醒

**目前版本為純前端原型，資料儲存在使用者目前瀏覽器的 localStorage。**

- 不會自動同步到另一台電腦、另一個瀏覽器或其他同仁的裝置。
- 清除瀏覽器網站資料或更換裝置可能造成資料無法直接取回；請定期匯出 JSON 備份。
- 截止時間的自動鎖定只會在頁面開啟且 JavaScript 正在執行時檢查；瀏覽器關閉期間不會有伺服器背景排程。
- 本版沒有登入、角色權限或雲端資料庫。GitHub Pages 公開網址任何可訪問者都可能載入程式，因此不要用於記錄真實的員工姓名、電話、勤務或其他敏感資訊。
- 正式投入台電作業前，應依公司資訊安全與個資規範，接上經核准的登入驗證、伺服器端資料庫及操作權限；截止鎖定與操作紀錄也應在伺服器端實施，不能只依賴瀏覽器。

## 車型設定

初始值僅供測試：大巴門檻 20 人、小巴容量 19 人、大巴容量 43 人。請依實際租用車輛的核定乘客數及單位規範修改，系統建議不取代實際派車確認。

## 初次試用

1. 開啟首頁，點選「載入示範資料」可快速檢查介面與人數統計。示範勤務與人名皆為虛構資料。
2. 至「車型與截止設定」調整車型門檻及新勤務的預設截止時間。
3. 建立勤務，加入人員、登錄實際車輛。
4. 測試 CSV 匯出、列印、提前截止、重新開放及 JSON 備份／還原。
5. 正式使用前，先移除示範資料，並完成核准的資料庫與權限設計。
